# Tempo advertising video

30 seconds, 1920 × 1080, 60 fps. Seven native motion-graphics scenes: introduction, shifts, teams, check-in, time and pay, overview, and closing call to action.

The soundtrack is an original synthesized composition with transition effects, generated by `soundtrack.py`. No stock music is used. Product cards are illustrative motion graphics; names and earnings are demonstration data.

`tempo-ad.mjs` is the Higgsedit authoring source. The downloadable editable archive contains `project.json`, imported media, the authoring source, and the audio generator. Render the extracted project with Higgsedit:

```sh
higgsedit render /path/to/extracted/project --out renders/tempo-ad-30s.mp4
```

To rebuild from the authoring source, change the `/home/user/tempo-ad` project and soundtrack paths to your working directory, generate the soundtrack first, and run `higgsedit build tempo-ad.mjs`.

This is an editable Higgsedit project, not an Adobe After Effects `.aep` file.
